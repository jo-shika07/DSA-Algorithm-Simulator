# DSA Algorithm Simulator using C

## About the Project

DSA Algorithm Simulator is a simple C programming project that demonstrates sorting and searching algorithms using student marks. Users can select an algorithm from a menu and view the results.

## Features

* Enter student marks.
* Sort marks using Bubble Sort.
* Sort marks using Selection Sort.
* Sort marks using Insertion Sort.
* Search marks using Linear Search.
* Search marks using Binary Search.
* Display student marks.
* Simple menu-driven interface.

## Technologies Used

* Programming Language: C
* Compiler: GCC
* Editor: Visual Studio Code

## Algorithms Implemented

1. Bubble Sort
2. Selection Sort
3. Insertion Sort
4. Linear Search
5. Binary Search

## How to Run

1. Download or clone this repository.

2. Open the project folder in Visual Studio Code.

3. Open the terminal.

4. Compile the program:

   ```bash
   gcc main.c -o main
   ```

5. Run the program:

   ```bash
   ./main
   ```

   On Windows, use:

   ```bash
   .\main.exe
   ```
